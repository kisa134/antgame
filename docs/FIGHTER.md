# Боец и отряд: личная прокачка и ветераны

Ветка `code/ANT-fighter` (от `code/ANT-map4`). Код: `AntFighter.{h,cpp}` (таблицы, профиль, сервер), `AntVeterans.cpp` (ветераны),
`AntCosmetics.{h,cpp}` (облик), `AntFighterUi.{h,cpp}` (экраны). Стык с колонией — `AntMetaBus.h` (взят из `code/ANT-colony` 072dad3 без правок).

Принцип: **прокачка — вбок, не вверх.** Перки — сайдгрейды (каждый плюс оплачен минусом), облик ничего не даёт.
Ветеран 7-го звания и новичок несут один торт одинаково; плоского «+урон» нет нигде.

## 1. Профиль (у каждого игрока свой, локально)

- Файл: `Saved/Fighter/profile_<id>.json`, `<id>` — Steam id; без Steam — `local`. Для тестов на одной машине: `-AntProfile=A`.
  JSON с полем `Version`; запись через `.tmp` и переименование. Работает офлайн.
- Машина игрока шлёт серверу `FAntLoadout` (опыт, звание, перки, медали, облик) — он лежит в `AAntPlayerState::Loadout` и
  реплицируется всем: по нему каждая машина одевает муравья, сервер применяет перки.
- Сервер ведёт счёт рейда (`FAntFighterTally`) и в конце (`AntMetaBus::OnRaidSummary`) шлёт игроку строки опыта и медали
  (`ClientFighter`); профиль пишется на его машине.

## 2. Касты и деревья перков

Новая каста **Сапёр** (сила 11, здоровье 95, урон ×0.9): крепёж и ткань ×1.5. Выбор касты — в лобби (‹ ›) и в профиле.
Ярусы открываются званиями 1 / 3 / 5; в каждом ярусе 1 из 2, менять можно в гнезде сколько угодно.

| Каста | I ярус | II ярус | III ярус |
|---|---|---|---|
| Фуражир | Ломовой (сила +35 %, скор. −10 %) / Челнок (с лёгким грузом +25 % скор., сила −10 %) | Выносливый (HP +20 %, скор. −5 %) / Шустрые лапы (рывок ×0.7, HP −10 %) | Артельщик (+25 % силы, когда несут ≥2) / Одиночка (+25 % силы в одиночку) |
| Солдат | Щитоносец (урон по нему −25 %, скор. −10 %) / Кислотник (плевок −30 % кислоты, HP −10 %) | Таран (рывок ×0.6, прыжок −10 %) / Часовой (стоя −30 % урона, скор. −5 %) | Ополченец (рядом 2 своих: −15 % урона) / Берсерк (<30 % HP: скор. +25 %, урон по нему +15 %) |
| Разведчик | Ушной агент (внутри людей ×2 дольше, HP −10 %) / Попрыгун (прыжок +25 %, сила −15 %) | Бегун (без груза +10 %, HP −10 %) / Цепкий (по стенам +25 %, по полу −5 %) | Курьер (с грузом +15 %, сила −10 %) / Ныряльщик (мокрый +40 %, сухой −5 %) |

здоровье, прыжок, урон по муравью, кислота, рывок, лечение, время внутри людей, скорость работы руками.

## 4. Облик (реальный, реплицируется)

Слоты: каска (жёлудь, напёрсток, крышечка, колпачок маркера, полжёлудя), очки (бисер, монокль, капли росы), шея (шарф из нитки,
шайба, бантик из пряжи), оружие (спичка-копьё, зубочистка, горелая спичка), спина (рюкзак из шелухи, сахарная ташка, лист-плащ),
раскраска (мука, варенье, шоколад), хитин (янтарный, карамельный, угольный, медовый, Золото Щели), узор (крапинки, мак, полосы),
тропа (янтарная, мятная, вишнёвая, сахарная), жест (топот, усы-пропеллер, поклон Королеве, танец с крошкой — без отдания чести; [N]).
Каждый предмет открывается званием или медалью. `UAntDress` на каждом муравье переодевает его, когда меняется лоадаут.
Ветераны носят знаки своего звания. Трейлерные роли «cap kit» сохранены как `AntCosmetics::Apply(Ant, Role)`.

## 5. Ветераны отряда (казарма хоста)

- Файл хоста: `Saved/Nest/veterans.json` (ростер, стена памяти, занятые имена). Реплицирует `AAntFighterState`.
- Муравей отряда снежного кома, живой в конце рейда, становится ветераном (до 2 за игрока за рейд, ростер ≤ 30): имя («Изюм»,
  «Батя Сухарик»...), звание (Рядовой → Старшина: 0/100/250/500/900 опыта), причуда. Новые сразу записаны в отряд командира, если есть место.
- Причуды: боится воды · тащит за двоих · трус (бежит от кошки, вынюхивает еду и сообщает командиру) · ветеран тапка (50 % —
  тапок промахнулся) · железные жвала · счастливчик (один смертельный удар за рейд — 1 HP). Вторая причуда — на 2-м и 4-м звании.
- Перед рейдом: экран «КАЗАРМА» в гнезде — взять / отпустить, «набрать лучших». Лимит — `AntVets::DraftCapFor`: 2 + ярус
  «Солдат» (Казарма) + ½ яруса «Выводок», не больше 6 (**колония может заменить своей постройкой**).
- Гибель навсегда: в стену памяти с причиной на языке сеттинга («раздавлен Розовой Плитой», «пойман Тихой Лапой», «задохнулся
  Белой Погодой»…) и номером рейда. Разгром отряда — все вышедшие ветераны пропадают.
- Доктрины (по званию лучшего ветерана в отряде): **Клин** (ефрейтор: с грузом +15 %, плотный строй), **Рассыпной** (мл. сержант:
  строй ×2.2, +10 % скор., −10 % HP), **Черепаха** (сержант: −30 % урона, −10 % скор., кучно).

## 6. Экраны

- Гнездо: кнопки **БОЕЦ** и **КАЗАРМА** в шапке. Профиль: вкладки «Боец» (звание, полоса опыта, лестница званий, прошлый рейд по
  строкам), «Касты» (5 деревьев), «Медали» (стена 9×4), «Облик» (слоты ‹ ›, знаки, жест). Казарма: карточки ветеранов, мой отряд,
  доктрина, стена памяти.
- Итоги рейда: колонка «ИТОГИ БОЙЦОВ» поверх донесения — новые звания, медали, лучший подвиг, ветераны (повышен / новый / пал).
- В рейде: тост-значок медали справа; имя и звание ветерана над ним при наведении (как у прочих муравьёв).

## 7. Стык с колонией (`AntMetaBus.h`)

Подписка на `OnRaidSummary` (опыт, медали из `Feats`, повышения ветеранов), провайдеры `GetFallenVeterans` (стена) и
`GetPlayerHighlights` (итоги) работают на всех машинах из реплицированного `AAntFighterState`. Пока колония не влита, эта ветка
шлёт упрощённую сводку из `AAntRaid::BuildResult` (`AntFighter::BroadcastFallbackSummary`, вся еда как «крошки») — **при мёрдже
эту строку убрать**, версия колонии главная. Колония может добавить свои id подвигов в `FAntRaidPlayerLine::Feats`: известные ключи
(`cake_home`, `trophy_home`, `special_home`, `contract`, `last_out`, `survived`) уже превращаются в медали.

Стабильный API для обучения: `AntFighter::AwardRank(PS, Rank)`, `AwardMedal(PS, AntFeat::EId)`, `AwardMedalKey(PS, "slipper")`,
`OpenPerkPick(PS, Caste)`.

## 8. Ограничения

- Ветераны выходят только в рейде со снежным комом (по умолчанию); с `-AntNoSnowball` (старые отряды-армии) остаются в казарме.
- Опыт и медали доверяют машине игрока (кооп, не соревнование): сервер лишь отбрасывает облик, которого нет по званию/медалям.
- Жест «пропеллер/танец» — телом через удары-реакции (`NoteBodyAct`) и крошки над головой, не отдельной анимацией.
