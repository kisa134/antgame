# Ant Kitchen — карта экранов (code/ANT-ui)

```
запуск ──► Заставка (студия → логотип, 5.6 с, любая клавиша — пропуск, 1 раз за запуск)
             │
             ▼
        Главное меню ──► Играть ───────────────► (загрузка) ► Гнездо/Штаб ► рейд ► Донесение ► Гнездо …
             │          Кооператив ─► Создать (Steam) ─► (загрузка) ► Сбор отряда ► Штаб ► …
             │                      ─► Друзья в Steam ─► список ─► Войти ─► (загрузка) ► Сбор отряда
             │                      ─► По адресу: Подключиться / Хост без Steam (порт 7797)
             │          Колония (Королева, доклад, состав, «Основать новую Щель»)
             │          Настройки (Графика · Звук · Управление · Игра; Применить / Отменить)
             │          Титры
             │          Выход
В игре: Esc ─► Пауза (мир не останавливается в коопе) ─► Продолжить · Настройки · Пригласить · Сбор отряда · Главное меню · Выход
```

| Экран | Где | Класс / функция |
|---|---|---|
| Заставка, главное меню, кооп, колония, настройки, титры, пауза, сбор отряда | Slate поверх вьюпорта | `SAntUiMenu` (`AntUiMenu.cpp`), экраны `AntUiScreen::*` |
| Загрузка | MoviePlayer при каждой загрузке карты | `UAntUiSubsystem::OnPreLoadMap` → `SAntUiMenu(Loading)` |
| Штаб / гнездо (между рейдами) | Canvas HUD | `AAntHUD::DrawNest` (`AntHUDNest.cpp`, рестайл) |
| HUD рейда | Canvas HUD | `AAntHUD::*` (шрифты, полосы, иконки маркеров) |
| Выбор карты (снежный ком) | Canvas HUD | `AntUiCanvas::DrawCardPick` из `AntRts::DrawHud` |
| Донесение после рейда | Canvas HUD | `AntUiCanvas::DrawDebrief` из `AAntHUD::DrawRaidResults` |

Сбор отряда открывается сам у каждого игрока в коопе, пока идёт фаза гнезда до первого рейда; потом — из паузы
(«Сбор отряда») или консолью `AntLobby`. Готовность, каста, сид и «Я — Гигант» идут теми же серверными командами,
что и экран штаба (`ServerRaid Ready/Seed/Start`, `ServerToggleHuman`, `ServerSetClass`). Старт рейда закрывает экран.

Управление: мышь; клавиатура (стрелки/WASD — фокус по направлению, Enter/Пробел — выбрать, Esc — назад,
←/→ — менять значение, Q/E — вкладки настроек); геймпад (D-pad, A, B, LB/RB). ПКМ — назад.

Флаги: `-AntUiClassic` (старые экраны), `-AntUiOldFonts` (шрифт движка в HUD), `-AntUiShow=<Экран>`,
`-AntUiShots=Main,Coop,...` (+`-AntUiShotsQuit`) — скриншоты экранов, `-AntUiTest=cards|debrief|debrieflose` — Canvas-экраны на тестовых данных.
