# Админ-режим (v12)

Код: `Source/AntKitchen/AntAdmin.h/.cpp` (панель, команды сервера, бейдж, метки «показать всех»), правки в `AntPlayerController.*` (F10, `ServerAdmin`), `AntCharacter.*` (флаги админа), `AntKitchenGameMode.h` (`AdminCommand`), `AntHUD.cpp` (бейдж), `LevelV3.*` (время суток поверх сида). Строки лога: `ANTADMIN`.

## Как включить

- **F10** — открыть / закрыть панель в любой одиночной игре и у хоста кооп-игры. Esc тоже закрывает.
- **Ярлык `Ant Kitchen v12 ADMIN`** (на рабочем столе) = `AntKitchen.exe -AntAdmin -log`: панель открывается сама через 2–3 с после входа в игру (не поверх главного меню), в углу горит бейдж **АДМИН**. `-AntAdminClosed` — бейдж без автопанели.
- Игра не встаёт на паузу: клавиатура (WASD, прыжок, E) продолжает управлять муравьём, мышь — для кнопок. Нужно покрутить камеру — закрой панель (F10).
- Кнопки «у прицела» бьют в точку под центром экрана (прицел). Панель стоит слева, центр экрана открыт.
- **Кооп.** Админ есть только у хоста. Кнопка/команда клиента приходит на сервер и отклоняется (`ANTADMIN REJECTED` в логе, тост «Админ-режим есть только у хоста»). Панель у клиента не открывается.

## Командная строка (низ панели)

Любая команда + Enter. ↑/↓ — история (живёт до выхода из игры), Tab — дописать команду, под строкой — подсказка из первых совпадений. Всё, чего админ сам не знает, уходит в полный набор отладочных команд `-AntDo` (`AntRun.cpp` DevCommand и команды веток: `carry …`, `mess …`, `snow …`, `trail …`, `rts …`, `squad+ N`, `perf …`, `wreck …`, `weapon …`, `versus …`, `seed N`, `routine …`, `cat|dog|gran|kid …`, `hpuppet`/`hact`, `cap …` если есть, `q <cmd>`). Свои для этой машины: `con <консоль движка>` (например `con stat fps`, `con HighResShot 2`), `stat …`, `hudtoggle`, `film`, `freecam`.

## Вкладки и кнопки

### Я
- Бессмертие (`god`): урон, раздавливание, слизывание, падение за мир — муравей живёт, лапы не отрываются.
- Бесконечная кислота и рывок (`inf`): плевок бесплатный, рывок раз в 0,15 с.
- Полёт сквозь стены (`fly`): без столкновений, летит куда смотрит камера, Пробел — вверх, Ctrl — вниз.
- Суперсила (`strong`): сила 100000 — один уносит что угодно (торт тоже).
- Вылечить (`heal`). Скорость x1 / x2 / x5 / x10 (`speed X`, до 20).
- Телепорт: в точку прицела (`tpto`), в гнездо (`tphome`), к торту (`tpcake`), все места карты — вкладка «Телепорт».
- Каста: фуражир / солдат / разведчик / бочка (`caste N`). Груз: взять ближайшее, груз 10/60 в жвалы (`give`), 4 бота держат со мной (`helpers 4`).

### Телепорт
Гнездо, торт, прицел; 14 районов квартиры v3 (центр района, на верх того, что там стоит) — `tpd N`; все подписанные места карты v3 (стол, холодильник, диван…) — `tpc N`.

### Спавн
- Еда у прицела — кнопка на каждую еду игры (крошки, сахар, сыр, мармелад, торт-кусок, мишка, шоколад…; в скобках вес): `food x y z Имя`. Крошки ×5 / ×20.
- Торт: новый на своё место (`cake`), новый у прицела, торт ко входу в гнездо (`cakehome`).
- Муравьи: рабочие +12 / +50 на тропы (`workers N`; без тропы кладётся стартовая), отряд +1/+5/+10 (`squad N`), солдаты +3, боты-игроки +1 / до 8 (`allies N`), рыжие +1/+5 (`reds N`), рыжий передо мной (`enemy`), муха (`flyspawn`).
- NPC появиться у прицела / убрать: Человек, кошка, собака, бабушка, ребёнок (`npcshow who`, `npchide who`; who = human cat dog gran kid). «Убрать» прячет и выключает (без удаления), «сюда» возвращает.

### NPC
- Заморозить / разморозить всех (`freeze`), все спят / проснулись, смелость питомцев и семьи 0/1/2 (`npclevel`).
- Ярость Человека 0–3 (`rage N`), вселиться в Человека (`hplay`, ещё раз — назад), погром (`rampage`: ярость 3 + бита).
- Оружие Человека: газета, тапок, половник, лопатка, книга, скалка, сковорода, веник, бита, колбаса (`weapon give …`); «выбить оружие» — подменить колбасой (`weapon swap sausage`).
- По каждому (Человек, кошка, собака, бабушка, ребёнок): сюда (к прицелу), атаковать меня, уснуть, проснуться, пропустить шаг распорядка.
- У прицела: убить / нокаут (`killaim`), оглушить (`stunaim`). Муравья — убивает/опутывает, Человека и семью — нокаут/оглушение, питомца — пугает.
- Распорядок дня v3: день / вечер / ночь (`routine day|evening|night`: распорядок перестраивается, свет переходит за ~6 с), вперёд на 1 / 5 мин (`routine warp`), стоп / дальше, кто что делает (в лог).

### Мир
- Пауза / продолжить, скорость времени 0.25 / 0.5 / 1 / 2 / 4 (`pause`, `timescale`).
- Время суток: день / вечер / ночь / как в сиде (`tod`).
- Новый сид + перезапуск, перезапуск уровня (`restart`), поле «сид №» + «Применить сид» (`seed N`: квартира перекладывается сразу, еда — со следующего сброса), сид в лог.
- У прицела: сломать предмет v3 (`breakaim`), открутить все крепежи (`unfastenaim`), сломать мебель ударом (`wreck at … 220 40 400`, стадия разрушения +), разбудить физику (`wreck at … 320 6 0`), погром, разруха в лог.
- Пятно у прицела: варенье, мёд, кола, масло, крем, шоколад, сок, крошки, грязь, вода, сахар (`stainaim вид x y z размер`); убрать всю грязь (`cleanall`).
- Цепные реакции C1–C6 и «всё сразу» (`chain`, `state chaos`).

### Рейд
- Строка массы снежного кома (масса / следующий порог / выборов), масса +50 / +500 (`mass N`), выбор карточки сейчас (`picknow`), все улучшения (`allups`), автовыбор 1-й карты / выкл.
- Таймер: +5 мин (`addtime 300`), последний свет 30 с, 10 с (`settime`).
- Исход: мгновенная победа (торт домой, муравей домой, через 2,5 с рейд кончается), эвакуация, поражение, начать рейд.
- Режим «Против»: Человеком играет клиент / хост / ИИ (`versus start …`).
- Показать всех (`reveal`): метки сквозь стены над Человеком, семьёй, питомцами, рыжими, тортом и крупной едой, с расстоянием.
- Гнездо: еда +500, желе +100, личинки 10.

### Экран (только эта машина)
FPS (`stat fps`), статистика кадра (`stat unit`), скрыть/показать HUD, режим съёмки (F8), свободная камера (съёмка + F5), скриншот (`HighResShot 1`, файлы в `Saved/Screenshots`).

## Для тестов
`-AntAdminDo="t:cmd;t:cmd"` — команды панели в эти секунды тем же путём, что кнопки (RPC). `t:panel` открывает/закрывает панель, `t:aim cmd` дописывает к команде точку прицела (`aim killaim`, `aim stainaim jam`).

## Что делает каждая команда на сервере
Все кнопки — текст в `AAntPlayerController::ServerAdmin` → `AAntKitchenGameMode::AdminCommand` (проверка: контроллер локальный на сервере = хост/одиночка) → лог `ANTADMIN <игрок>: <команда>` и `ANTADMIN done: <итог>` → тост хосту и строка «последнее действие» в панели (реплицируется через `AAntAdminState`).
