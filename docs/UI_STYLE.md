# Ant Kitchen — UI style: «кухонный штаб» (kitchen war-room)

Ветка `code/ANT-ui`. Код: `Source/AntKitchen/AntUi*.{h,cpp}`. Арт: `SourceArt/UI/` → `/Game/UI/` (`Tools/make_ui_assets.py`).

## Идея

Интерфейс — это **документы и техника Колонии**, собранные из человеческого мусора: картон от хлопьев, чековая лента,
малярный скотч, крышечки, спичечные коробки, штампы вареньем, пометки карандашом и мелком. Фоны — макро-съёмка кухни
с высоты 8 мм (стиль A: стилизованное 3D «как у Pixar»; стиль D пока не используется — портреты и плакаты сделаны в A).
Читаемость важнее стилизации: цифры и кнопки — чистым шрифтом, стиль живёт в рамках, заголовках, фонах и звуках.

Жёсткие правила сеттинга: никаких флагов и государственных символов, никаких красных крестов (медик — зелёный лист с бинтом),
никаких одиночных Z/V, ничего похожего на знаки реальных армий. Салют — оба усика к каске (поэтому на карте «Пополнение»
муравьи без отдания чести). Первый вариант логотипа (лучи «восходящего солнца» за буквами) отброшен по этому правилу.

## Сетка и отступы

Макет 1920×1080, масштаб `U = min(W/1920, H/1080)`, центр. На 21:9 и шире растягиваются только фоны (поэтому для меню
сгенерированы плиты 21:9), раскладка остаётся в безопасной зоне 16:9. Поля: 70 px слева/снизу, 120 px у колонки меню.
Шаг меню 66, строки настроек 66 (56 высота + 10), карточки отряда 300×236 с зазором 18.

## Компоненты

- **MenuButton** — слово на тёмном; в фокусе под него «наклеивается» полоска скотча (`T_UI_Tape`, Honey), буквы темнеют, сдвиг +16.
- **Button** — скруглённый (10) картонный ярлык; главный — янтарный, второстепенный — InkSoft с рамкой, подъём −3 в фокусе.
- **OptionRow / SliderRow / ToggleRow** — строка на чернильной подложке, слева полоска фокуса Amber, справа значение ‹ › / ползунок / тумблер.
- **EditField** — бумажная полоска с моноширинным текстом и мигающим курсором.
- **Paper** — лист чековой ленты с тенью и двумя кусками скотча. **Glass** — тёмная панель с краем Cocoa.
- **Stamp** — рамка из `T_UI_StampBox` + слово, наклон −6…−9°.
- **HUD Bar** — чернильная дорожка, заливка, светлый блик сверху, риски через 10 %.
- **Card** (выбор снежного кома) — рамка цвета редкости, картон, иллюстрация 3:4 в окне, кубик сахара с номером клавиши, лента пула с иконкой.

## Движение

- Переход экрана: проявление 0.25–0.35 с (ease-out cubic), элементы въезжают на 20–30 px с задержкой 0.07–0.08 с между соседями.
- Фокус: значение 0→1 с интерполяцией 14/с; всё (скотч, цвет, сдвиг) от него.
- Фон меню: медленный «наезд камеры» (зум 1.07±0.025, панорама синусами 0.04–0.07 Гц) + параллакс от мыши, 70 пылинок в трёх глубинах.
- Логотип на заставке — ease-out-back; донесение печатается со скоростью 70 знаков/с, штамп «падает» с 1.5× масштаба.
- Никаких мигающих элементов быстрее 1 Гц кроме курсора ввода.

## Производительность

Меню — один виджет immediate-mode (`SAntUiMenu`), без UMG. Пока поверх кухни открыт непрозрачный экран (главное меню,
кооп, колония, титры, сбор отряда), мир не рисуется (`bDisableWorldRendering`). HUD: добавлено несколько тайлов на кадр
(иконки маркеров, полосы) — в пределах 0.1 мс; шрифты рантайм-кэша Slate.
