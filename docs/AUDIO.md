# Ant Kitchen — sound and music (branch code/ANT-sound)

Everything audible in the game goes through one module: `Source/AntKitchen/AntAudio.h/.cpp`.
Licences and sources of every file: `docs/AUDIO_CREDITS.md`. Feature summary: `docs/FEATURES.md`, section 28.

## 1. Audit (before this branch, code/ANT-heist-core @ 209cf29)

How sound worked:
- `AntSfx` (AntTypes.cpp): 39 ids, each loaded by path from `/Game/SoundsReal/S_<Name>` plus a blind probe of `S_<Name>_1..4`.
  38 ElevenLabs files existed; most ids had one variation (steps 4, Human steps 2).
- One attenuation for everything (500 uu inner, 6500 uu falloff): an ant's footstep and the Human's stomp carried the same distance.
- No SoundClass, no SoundMix, no concurrency limits, no volume settings, no music at all, ambience switched off
  (`AntPlayerController.cpp`: `if (USoundBase* Amb = nullptr)`).
- `AntSfx::Everyone` → `AAntGameState::MulticastSfx` → every machine plays it (unreliable multicast). This stays.

The cook / packaged-build warning "missing /Game/SoundsReal/* packages": the sounds that exist *were* cooked
(`DirectoriesToAlwaysCook=/Game/SoundsReal`, they are in the pak manifests). The warning came from the probing:
`AntSfx::Get` asked for `S_Spit_1`..`S_Spit_4`, `S_Step`, `S_Step_Wood`.. — about 150 packages that never existed. Each failed
`LoadObject` of a missing package is reported by the packaged loader. Fix: `AntAudio` lists the exact files of every id
(`"A_StepTile*5"` = `A_StepTile_1..5`), nothing is probed; a real miss is logged once as `ANTSFX missing <path>`.

Gameplay events that had no sound or a weak one (all now covered, see section 3):

| Event | Before | Now |

| Human: picks something up | silent | grab-and-lift |
| Human: rage level up | `S_Rage` | + a roar |
| Human: idle | silent | grumbles when angry, sniffs about when looking |
| Human steps | 2 light thuds | 4 huge thuds with a sub-bass boom, heard across the flat |
| Slipper stomp | `S_Stomp` | + a rubbery slap |
| Cat / dog | hiss, swat | purr loop near a sleeping / sitting cat, pounce, hiss when frightened; dog sniffs (nose down), snorts, barks |

## 2. Music

All music is ours: generated by `Tools/audio/make_music.py` with the small synthesizer `Tools/audio/synth.py`
(FM electric piano, bass, clavinet, brass, pads, vibes, glockenspiel, whistle, tuba, trombone, synthesized drums, convolution
reverb). Loops render into a circular buffer (notes and reverb tails wrap to the start), so every loop is sample-seamless;
`Tools/audio/check_loops.py` checks the seams.

| Set | Use | Key / tempo | Loop | Layers |
|---|---|---|---|---|
| Nest — «Марш Великой Колонии Щели» | nest, menu, results | Bb, 100 BPM, march snare + tuba oom-pah, whistle tune, brass and glock reprises | 76.8 s | 1 |
| Funk | raid (odd raids first) | D dorian, 98 BPM, A A B B A A | 117.6 s | Base, Tension, Action, Urgency |
| Lounge | raid (even raids first) | A minor lo-fi bossa, 88 BPM, vinyl crackle | 109.1 s | Base, Tension, Action, Urgency |

- Base: drums, bass, keys, a vibes hook in the B sections. Tension: shaker, a muted 8th pulse, a dark string pad, rim ticks, toms,
  a riser every 4 bars. Action: four-on-the-floor, claps, crashes, clav stabs, brass stabs, the bass an octave up, tom fills.
  Urgency ("последний свет", the last 30 s): woodblock clock, timpani, tremolo strings, risers.
- Stings: RaidStart (fill + brass hit), Win (fanfare), Fail (sad trombone), Card (glock sparkle), LastLight (riser + stab).
- Loudness: Base+Tension of each set at about -17.5 LUFS, all four layers about -15 LUFS, peaks under -0.5 dBFS.

### The director (`UAntAudioSubsystem`, every machine but a dedicated server)

Reads replicated state only, so each machine hears its own mix of the same game:
- which set: `AAntRaid::Phase` (Nest → the march; Raid → Funk/Lounge by raid number; Results → the march) or, with no raid actor,
  `AAntGameState::Phase` (0 = playing). After two loops of a raid set (about 4 min) it crossfades (4 s) to the other set,
  only at a calm moment.
- every 0.2 s two numbers: **tension** = the nearest resident's proximity scaled by his rage, or the replicated Human rage;
  **action** = a chase (a resident moving towards you, the spray, a cat or dog stalking / in the air) + excitement (crashes,
  breaks, stomps, slaps, roars, falls, weapon blows near you push it up; it decays 0.07/s) + rage 3 with him near.
  Danger alone never brings the chaos layer: when the noise stops the music settles back. Versus / war: action >= 0.55.
- layers: Base always; Tension from 0.2..0.55 of max(tension, action); Action from 0.3..0.65 of action (up fast, down slow);
  Urgency when `TimeRemaining <= 30` (Tension held at 0.7 under it).
- stings on phase changes (raid start, results: win if `Result.End == Left`, else fail), card picked, last light.
- ducking: `AntAudio::Duck(Ctx, Seconds)` and every sting dip the music to 45 % (and push `SM_AntDuck`).
- the four stems of a set start in the same frame, are force-inline and play-when-silent (never virtualized), so they stay locked.

## 3. Sound effects

`EAntSfx` (AntAudio.h): 93 ids (0..38 are the old `AntSfx` ids, same numbers, so the old multicast carries the new ones).
The table in AntAudio.cpp gives each: files (variations), volume, random pitch, falloff, mix class, voice limit (concurrency),
cooldown, an "also" layer and how much it excites the music. Never the same variation twice in a row.

Falloffs (1 m = 1900 uu, an ant ≈ 15 uu, the Human ≈ 3350 uu), natural-sound curve with a distance low-pass:

| Preset | Inner / falloff (uu) | For |
|---|---|---|
| Tiny | 120 / 1600 | ant feet, jumps |
| Small | 300 / 3800 | bites, spit, grabs, screws, trails |
| Medium | 900 / 9000 | splats, hinges, pets' small sounds, delivery |
| Large | 2500 / 22000 | slaps, swats, bat swings, pets' voices |
| Huge | 5000 / 42000 | Human steps, crashes, roars, the kid's shout |

Sounds beyond their reach are not started at all (no voice slot used): 100 workers' feet cost nothing far away.

New files: 132 SFX WAVs (`SourceArt/Audio/Sfx`, `/Game/Audio/Sfx`): ant footsteps 25 (5 surfaces x 5), ant actions /
carrying / delivery / trails / swarm 36, the flat 24 (fasteners, falls, 5 crash materials, food), the Human 18, cat and dog 13,
grandma / kid / spider 7, UI 3, ambience loops 6. Plus 14 music files (9 loops, 5 stings).

## 4. Mix and settings

- SoundClasses `/Game/Audio/Mix/SC_Master` > `SC_Music`, `SC_Sfx`, `SC_Voice`, `SC_Ui`, `SC_Ambience` (set on every new wave);
  SoundMix `SM_AntDuck` (music 0.45, ambience 0.6).
- Volumes (console, saved to GameUserSettings.ini `[AntAudio]`): `ant.Audio.Master`, `ant.Audio.Music` (0.8), `ant.Audio.Sfx`,
  `ant.Audio.Voice`, `ant.Audio.Ui`, `ant.Audio.Ambience`; `ant.Audio.MusicMute 1`, or the **M** key (Ctrl+M is ignored).
  No settings screen exists yet: these are the values a slider should set.
- Dev: `ant.Audio.Log 1` or `-AntSfxLog`: every sound played (`ANTSFX <id> <file> v= p= d=`) and the music state every 2 s
  (`ANTMUSIC set= I= base= ten= act= urg=`). `ant.Audio.ForceIntensity 0..1` pins the intensity, `ant.Audio.ForceUrgent 1`.
- CPU: the director ticks cheaply every frame (volume smoothing); world scans run every 0.12 s (fasteners, fixtures, residents)
  and 0.25 s (pets) with class iterators; all sounds are one-shots or a handful of loops.

## 5. The v12 systems (merged: carry, mess, swarm, wreck, versus, admin) — all hooked

Most of it is read from replicated state by `UAntAudioSubsystem::TickV12` (no edits in their files); the rest are single lines.

| System | Event | Sound | Where |
|---|---|---|---|
| Carry | a carrier's shout («Раз-два, взяли!», «Тяни!»...: `CarryNet.BarkSeq` changes) | a tiny chorus (`ArmyCharge`, quiet) + music ducks 0.9 s | subsystem, every machine |
| Carry | in rhythm (`CarryNet.bRhythm`, 2+ grips) | `CarryBeat` every stride (thump + creak) | subsystem |
| Carry | out of step | load strain creaks (louder when `Sync` is low) | subsystem |
| Carry | `AntCarry::Events()`: dropped / broken / snatched / joined | release, splat, the Human's grab, a grab | subsystem binds the delegate on the server, multicasts |
| Mess | every burst (`AAntMess::MulticastBurst`) | `AntAudio::ForMess(Kind)`: jam/honey/mud splat, cream, cola/juice fizz, oil/water splash, crumbs/sugar | AntMess.cpp, 1 line |
| Mess | an ant with sticky feet leaves a track | `StepSticky` | AntMess.cpp `TickAnts`, 1 line |
| Swarm | workers on trails (`AAntTrailNet::Lines`) and swarm streams (`AAntSwarm::Streams`) | one patter loop at the nearest point, level from the count | subsystem |
| Swarm | a trail starts being laid | shimmer | subsystem (`Lines[].bLaying`, and `AAntCharacter::bLayingTrail`) |
| Swarm | a trail is cut (`AAntTrailNet::Cut`) | snip + tiny squeaks | AntTrail.cpp, 1 line (server → everyone) |
| Snowball | my 1/2/3 cards dealt / picked / colony level up | card flip / card pick + Card sting / chime | subsystem (`AAntSnowball::Players`) |
| Wreck | a piece struck (`TakeHit`) | `AntAudio::ForWreck(Mat, false)`: wood thwack, metal clang, glass/china crunch, plastic, soft, food | AntWreck.cpp (replaces the old Crunch/Stomp) |
| Wreck | a piece leans (stage 2) | wobble groan | AntWreck.cpp, 1 line |
| Wreck | a piece breaks apart | `ForWreck(Mat, true)`: wood / glass / china / metal / plastic crash, food splat | AntWreck.cpp (replaces Crunch) |
| Weapons | the Human swings a held weapon (`Act` = Swat with a weapon) | whoosh (bigger for heavier tiers) | subsystem |
| Weapons | the swing lands (`AntWeapons::OnSwingLanded`) | `ForWeapon(Kind)`: slipper slap, ladle/pan clang, book thud, rolling pin/bat thwack, broom swish, sausage splat | AntWeapon.cpp, 1 line |
| Human | peers under furniture (`Act` = Peer) | sniffing | subsystem |
| Versus / war | a player is the Human | music intensity never below 0.5 | director |
| Admin panel | tab «Экран» | «Музыка: вкл/выкл», volume − / + for music, sounds, voices, room, all | AntAdmin.cpp |

Every crash, break, slap, roar and fall near the listener also pushes the music towards the action layer (the table's excite
column), so destruction and versus fights get the chaos layer by themselves.

To add a sound to new code: `AntAudio::Play(this, EAntSfx::X, Where, Intensity)` (local) or `AntAudio::Everyone(...)` (server).

## 6. Pipeline

1. `Tools/audio/raw_manifest.txt` — the Higgsfield takes (name | seconds | URL). Download to `Saved/AudioRaw/`.
2. `python Tools/audio/make_sfx.py <project>` — cut / trim / level / loop → `SourceArt/Audio/Sfx/A_<Name>_<k>.wav`.
3. `python Tools/audio/make_music.py <project> [funk lounge nest stings]` → `SourceArt/Audio/Music` (+ UI chimes into Sfx).
4. `python Tools/audio/check_loops.py <wavs>` — seam check; `contact_sheet.py out.png <wavs>` — spectrogram sheet for a visual QA.
5. `UnrealEditor-Cmd.exe AntKitchen.uproject -run=pythonscript -script=<abs>/Tools/audio/import_audio.py -unattended -nosplash -nullrhi`
   → `/Game/Audio/{Sfx,Music,Mix}` (classes, looping, inline music). `/Game/Audio` is in `DirectoriesToAlwaysCook`.
6. New id: add it to `EAntSfx`, a row to `Table` and `Names` in AntAudio.cpp (same order; a static_assert counts them).
