# Онбординг

Два онбординга в одном файле: **игрока** — «Учебка Сержанта Жвалова» (часть 1) и **человека в команду** — доступы и установка (часть 2, как было).

# Часть 1. «Учебка Сержанта Жвалова» — онбординг игрока (ветка `code/ANT-tutorial`)

Цель: за 20–30 минут новичок пробует каждый основной глагол игры, видит свободу экспериментов, получает первый прогресс (звание, медаль, подарок колонии) и хочет в настоящий рейд. Код — `Source/AntKitchen/AntTutorial.h/.cpp`; демо Steam — `docs/DEMO.md`.

## Принципы

- **Показать, а не рассказать.** Один новый глагол на этап, сразу проверка и награда (teach → test → payoff).
- **Диегетика.** Ночь, семья спит, Гигант дремлет на диване — кухонный пол становится полигоном сержанта. В главе 3 Гигант просыпается.
- **Короткие реплики** сержанта (субтитры + «радио-лай» — синтезированная тарабарщина, как в Animal Crossing; озвучка позже, список ниже). [Enter] — обрезать реплику.
- **Подсказки клавиш** в стиле нового UI: карточка цели справа сверху (шаги с клавишами-кнопками, счётчики, точки по игрокам в коопе), метки в мире с расстоянием, штамп «ВЫПОЛНЕНО» + XP.
- **Никто не застревает.** Через 0,6 пара — подсказка, через пар — «[Enter] — сержант поможет» (телепорт к месту / сделать шаг за тебя). Хост может пропустить этап (держать [Enter] 1,2 с). Смерть в учебке = возврат на чекпоинт этапа, не конец.
- **Свобода.** После цепных реакций — «Свободный полигон» 50 с (метки «можно уронить»), после учебки — «Песочница».
- **Кооп 1–4.** Каждый видит свой чек-лист; командные шаги (отряд) засчитываются всем; этап закрывается, когда все сделали свои шаги.

Ветки, которые ещё не влиты, включаются **сами** при мёрдже (проверка `__has_include` + текстовые команды):
- **chains** (`AntReact.h`): этап 11 — перец/мука/пробки; позиции реквизита ищутся рефлексией (`AntReactProp.Kind`), команды `chain C7`, `chain C8`, `power short`, `power on`.
- **life** (`AntLife.h`): пока ничего не требует; в песочнице можно добавить `tv …`, `life vacuum` (см. ниже).
- **colony** (`AntColony.h` + `AntColonyView.h`): подарок Королевы идёт через `AntColony::GiveGift` (сахар 150, белок 80, жир 40, крошки 120, молочко 2, личинка, 4 рабочих) при первом настоящем рейде; без ветки — `Nest.Food += 150, Jelly += 2, +1 личинка, +4 рабочих`.
- **fighter** (`AntFighter.h`): на выпуске `AntFighter::AwardRank(PS, 0)` (Рядовой) и `AwardMedalKey(PS, "slipper")`. Перки каст открываются со звания 1 (Ефрейтор) — учебка их **не** выдаёт, только показывает тизер (решение: учебка даёт Рядового; первый перк — после первого настоящего рейда).
- **metabus** (`AntMetaBus.h`): на выпуске — `OnRaidSummary` с подвигами `tutorial_done`, `survived` (RaidNo 0).

## Где и как поставлено

Обычный мир рейда (карта v4, сид 7, угроза 1) + режиссёр `AAntTutorial` (реплицируемый `AInfo`), который **владеет часами рейда**: в `AAntRaid::RaidSecond` нет стадий, событий, таймаута; красного клана, особых находок, ботов-«игроков» и мух нет; масса снежного кома заморожена до этапа 5; стартовой тропы и отряда нет (выдаются в своих этапах). Ночь (`routine night`), Гигант идёт дремать на диван (`routine goto h_nap`, затем `routine off`), кошка, Бадрик, бабушка — `npcsleep`. Учебка играет **на своей колонии** (`Saved/NestTutorial`), настоящая (`Saved/Nest`) не трогается.

Постановка — те же текстовые команды, что у админки и `-AntDo` (`AAntKitchenGameMode::StageCommand`: без тоста, работает и в демо без админ-панели): `food x y z Имя`, `flyspawn`, `fix fall jam_jar`, `cloth crew tablecloth 6 0 -1 10`, `fluid flood 14 30`, `fluid geyser x y z 8`, `chain C3`, `inside put human ear`, `npcwake dog`, `routine goto h_fridge`… Проверка шагов — по состоянию игры (движение и нормаль поверхности, `Carrying`, `AntCarry::Feel`, снежный ком, тропы, задания отряда, крепёж, ткань, вода, `AAntInsideNet`), плюс 4 крючка (`AntTut::Note`: рывок, плевок, укус, доставка, убийство).

Места (uu): выход из гнезда (-6450, -2500); стена кухни x = -7000; полка с банками (-7000, -800…800, z 2460–2640); стол со скатертью (533, -571), край (540, -2700); вентиль крана (-3250, 4800, 1830); гейзер (-3200, 1600); диван Гиганта (12300, -1100); укрытие — журнальный стол (13750, -3400); финал — кусок торта (-1500, -1900).

## Меню

- **Первый запуск:** первая кнопка главного меню — «Учебка Сержанта Жвалова», рядом записка «Новобранец? Начни с учебки — 25 минут». После выпуска первая кнопка — «Настоящий рейд», появляются «Учебка: главы» и «Песочница».
- **«Учебка: главы»** (`AntUiScreen::Training`): 16 этапов (печать у пройденных, `*` — упрощено до мёрджа ветки), «С начала», «Вдвоём–вчетвером (кооп)» (ведёт на экран кооператива — хост создаёт игру, учебка идёт у всех), «Песочница».
- **Песочница:** вся квартира, Гигант по распорядку; F2 — еда у прицела (6 видов по кругу), F3 — Гигант/семья стоп/ход, F4 — время суток, F5 — цепная реакция C1–C6 по кругу, F6 — потоп/сушь, F7 — сброс уровня, F10 — полная админка (не в демо).

## Прогресс и телеметрия

- Прогресс: `Saved/Tutorial/progress.ini` (демо: `Saved/Demo/progress.ini`): `done`, `beats` (биты этапов), `xp`, `rank`, `medals`, `gift` (подарок ждёт первого настоящего рейда), `best` (лучшее время), счётчики демо.
- Телеметрия: `Saved/Tutorial/telemetry.csv` — `session,time,beat,id,event,beat_seconds,par,retries,assists,skipped,players,xp`; события `start, stage, done, skipped, assist, death, fail, finish`. В логе — строки `ANTTUT`.

## Ключи и команды

- `-AntTutorial[=N]` — сразу учебка (с этапа N), `-AntSandbox` — песочница, `-AntDemo` — демо-сборка (`docs/DEMO.md`).
- `-AntTutAuto` — сценарный прогон: муравей хоста играет сам через те же серверные вызовы, что и клавиши (ходьба `bDevGo`, бег, прыжок, рывок, плевок, укус, взять, тропа `DevLay`, приказ отряду `AntRts::Assign`, E у вентиля/края скатерти, «в ухо/нос»); где без экрана не сыграть — помощь сержанта (в логе `HELP`). Скриншоты каждого этапа: `ANTTUT shot NN_id_prompt|payoff`. `-AntTutQuit` — выход после выпуска, `-AntTutStay` — не уходить в меню.
- `-AntDo` / админ-строка: `tut info | skip | beat N | assist | enter | auto 1|0 | end`.

# Часть 2. Онбординг в команду Ant Kitchen

1. **Аккаунты на одну почту:** Claude (Pro или Max), GitHub, Atlassian (приглашение в Jira придёт на почту), Epic Games.
2. **Доступы:** скинь Юре GitHub-ник → прими приглашение в репо. Прими приглашение в Jira https://antgame.atlassian.net
3. **Установка (Windows):**
   - Unreal Engine **5.8** (ровно эта версия) через Epic Games Launcher;
   - Visual Studio 2022 с компонентами «Разработка игр на C++» (галочка *Unreal Engine installer*) и «Разработка классических приложений на C++»;
   - Git + Git LFS, потом в терминале `git lfs install`. Для ручной работы удобен GitHub Desktop.
4. **Проект:** `git clone https://github.com/kisa134/antgame`, ветка `main`. Двойной клик по `AntKitchen.uproject` → на *Rebuild?* жми **Yes** (компиляция долгая) → **Play**.
5. **Claude:**
   - Settings → Connectors → **Atlassian** (на экране согласия выбери сайт **antgame**) и **GitHub**;
   - в Claude Desktop дай доступ к папке с репо;
   - первое сообщение: «Прочитай CLAUDE.md, README.md, docs/ и покажи мои задачи в Jira ANT».

Правила работы — в `CLAUDE.md`. Коротко: задача в Jira → ветка → `git lfs lock` перед правкой `.uasset` → PR с ключом задачи → отчёт в Jira.
