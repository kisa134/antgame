# Словарь Ant Kitchen

Одно слово = одно значение (FPF A.1.1, F.17). Новый термин — новая строка в том же PR, где он впервые появился.

| Термин | Значение в проекте | Не путать с |
|---|---|---|
| Муравей | персонаж игрока или бота, ~8 мм в реальном масштабе | армейский муравей |
| Армейский муравей / рабочий | дешёвый юнит роя, выводится из резерва клавишей F | игрок-муравей |
| Каста | класс муравья: Фуражир, Солдат, Разведчик, Бочка | роль в команде разработки |
| Человек | враг-гигант (тапок, дихлофос); ИИ или игрок по H | — |
| Муравейник / гнездо | база стороны, безопасная зона | территория |
| Территория | зона захвата в режиме «Муравьиная война» (6 шт.) | касса |
| Касса | точка, куда доносят сейф-сахарницу и удерживают 45 с | муравейник |
| Сцепка | действие на G: живая лестница, мост, перенос | — |
| Лут / еда | предметы, которые тащат в гнездо; у каждого есть вес | оружие |
| Задача | WorkPlan: карточка в Jira `KAN` | сделанная работа |
| Сделано | есть смёрдженный PR (Work) | «написал код локально» |
| Роль | зона ответственности (код, арт, приёмка) | конкретный человек |
| Зона | папки, которые роль меняет без согласования (см. CLAUDE.md) | — |
| Исходник арта | FBX/GLB/текстуры из Meshy в `SourceArt/` | импортированный `.uasset` |
