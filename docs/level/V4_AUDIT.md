# Карта v4 — аудит примитивов и заглушек (22.11.2026)

Ветка `code/ANT-map4` (от `code/ANT-v12`, cd9c59e). Инструмент — команда `art audit` (`-AntDo "20:art audit"`, код `Source/AntKitchen/Map4.cpp`):
обходит все видимые компоненты мира и считает
- **primitives** — меши из `/Engine/` (BasicShapes Cube/Sphere/Cylinder/Cone/Plane);
- **flat_paint** — материалы-заглушки движка (BasicShapeMaterial, WorldGrid, DefaultMaterial);
- **generic_shapes** — собственные базовые формы v4 (`SM_M4_Box/Ball/Cyl/Cone/Plane`) на предметах — честный счётчик «кубиков и шариков», которые ещё не стали настоящими моделями;
- **generic_architecture** — те же формы как стены, полы, потолки, полки (плиты по природе);
- **procedural** — процедурные меши (обломки разрушения, лужи).

Пишет `Saved/map4/art_audit.csv` (по видам) и `art_audit_full.csv` (по компонентам с координатами и районом).
Отладочные помощники помечаются тегом `AntDebug` (`Map4::MarkDebug`) и не считаются.
