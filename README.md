# 🐜 Ant Kitchen — муравьиный лутер-шутер на кухне

Сетевая игра на Unreal Engine 5 (C++). Вы — муравьи. Лезете на кухню, лутаете ништяки
(крошки, сахар, сыр, торт, мармеладки) и тащите их в муравейник. Мешает **Человек**:
он топчет тапком и брызгает дихлофосом. Человеком управляет ИИ, но любой игрок
может взять его себе (клавиша **H**).

Кухня, муравьи, Человек, лут и интерфейс строятся **кодом прямо при запуске** из
стандартных фигур движка. Поэтому в репозитории нет бинарных ассетов: всё в `Source/`.

## Что нужно установить

1. **Unreal Engine 5.8** (проект собран под 5.8; если у тебя другая версия,
   кликни правой кнопкой по `AntKitchen.uproject` → *Switch Unreal Engine version*).
2. **Visual Studio 2022** с компонентами:
   - «Разработка игр на C++» (Game development with C++), там галочка *Unreal Engine installer*;
   - «Разработка классических приложений на C++»;
   - Windows 10/11 SDK и .NET (ставятся вместе с ними).
3. Git, чтобы склонировать репозиторий.

## Как запустить

1. `git clone https://github.com/kisa134/antgame` и переключись на ветку `claude/happy-volta-gwuaqo`.
2. Дважды кликни `AntKitchen.uproject`. На вопрос *«Modules are missing or built with a different
   engine version. Rebuild?»* жми **Yes**: движок сам скомпилирует C++.
   - Если компиляция упала: правый клик по `.uproject` → *Generate Visual Studio project files*,
     открой `AntKitchen.sln`, выбери `Development Editor` и собери (Ctrl+Shift+B).
     Текст ошибки скидывай мне, поправлю.
3. Откроется пустая карта. Жми **Play**: кухня соберётся сама.
   - Если редактор открыл какую-то другую карту: *File → New Level → Empty Level*, сохрани как
     `Kitchen`, жми Play. Игровой режим глобальный, он работает на любой карте.

## Управление

| Муравей | |
|---|---|
| WASD / мышь | ползти и целиться. **Муравей ползёт по любой поверхности**: упёрся в стену — пошёл вверх, дошёл до края стола — перевалил на бок, можно по потолку и низу шкафов |
| ЛКМ | плевок кислотой (зажать — очередь) |
| E | **схватить / отпустить еду** (её тащат физически, см. ниже) / взять оружие / **использовать штуку** (кран, дверь холодильника, духовка, ящик, свет, тостер, вентиляция, слив) |
| ПКМ | **укус**: рывок вперёд, урон и отброс врага, выбивает у него груз; по большой еде — **откусывает кусок**, который сразу хватаешь |
| 1–4 | каста (только в своём муравейнике): Фуражир / Солдат / Разведчик / Бочка |
| V | **bodycam**: камера на голове муравья, рыбий глаз, зерно, тряска |
| Shift | спринт |
| Пробел | прыжок / оттолкнуться от стены / отцепиться от потолка. Прыгнул на стену — прилип |
| H | стать Человеком |
| Tab | таблица игроков |

| Человек | |
|---|---|
| WASD / мышь | ходить и смотреть |
| ЛКМ | топнуть тапком (под ногой, по полу) |
| ПКМ (держать) | дихлофос (бьёт по муравьям на столах; топливо восстанавливается) |
| H | снова стать муравьём (Человеком опять рулит ИИ) |

## Режим «Набег» (основной)

Две колонии против друг друга и против Человека (PvPvE):
- **Мы** — чёрные муравьи, гнездо у западной стены. **Огненные муравьи** — красный муравейник у мусорки.
  По умолчанию: 2 бота-союзника и 3 бота-врага (`-AntBots=2,3`, в консоли `AddBot 0 2` / `AddBot 1 3`).
- Побеждает колония, первой натаскавшая **1500 сладости**. Если время (10 мин) вышло — у кого больше;
  при ничьей — Человек. Чем больше натаскано, тем злее Человек (**ярость 0–3**: быстрее ходит,
  чаще топает, дальше и больнее брызгает).
- **Еду тащат физически.** У каждой еды вес, у каждого муравья сила (Фуражир 14, Солдат 20, Разведчик 7, Бочка 10).
  Сила ≥ веса — несём (можно даже по стене), ½…1 — волочём по полу, меньше — не сдвинуть: зови своих.
  Торт, шоколад, золотого мишку тащат 2–4 муравья. Если враги вцепились в ту же еду — **перетягивание**.
- **Еда бьётся.** Скинь шоколадку со стола или холодильника — разлетится на куски, которые утащит и один.
  Укусом можно отгрызать куски от большой еды. Топот Человека и взрывы кислоты подбрасывают еду,
  в раковине с водой она всплывает и кружится.
- Касты: **Фуражир** (сильный), **Солдат** (броня, урон), **Разведчик** (быстрый, высокий прыжок), **Бочка** (лечит своих рядом).
- Огонь у союзников не ранит (нет friendly fire). Свой муравейник — безопасная зона.
- Оружие падает с редкостью: Обычное / **Редкое** / **Эпическое** / **Легендарное**; есть криты (×2), хитмаркеры, серии убийств.

## Стихии

- **Огонь**: на раскалённом (конфорка, духовка) или от искры провода муравей **загорается** — теряет здоровье
  и **поджигает всех, кого касается** (врагов тоже!). Тушится водой.
- **Вода**: делает мокрым (медленнее), тушит огонь, в раковине можно утонуть.
- **Электричество**: провод за холодильником искрит; ток бьёт по луже и **проходит цепочкой по мокрым муравьям**.
- **Холод**: холодильник и морозилка замораживают.

## Кухня живая

**Температура.** У муравья есть температура тела (видна над здоровьем).
- Горячо (конфорка, духовка, кипяток в раковине, тостер) — выше 55° горишь.
- Холодно (холодильник −7°, морозилка −20°, холодная вода) — медленнее бегаешь и стреляешь;
  ниже −5° **замерзаешь**: покрываешься льдом, не прыгаешь, отваливаешься от стен, теряешь здоровье.
- В муравейнике тепло, там всё проходит.

**Липкое и мокрое.** Мёд (стекает со шкафчика по западной стене в лужу) и варенье (на столе и в холодильнике)
— липнешь: скорость ×0.35 и без прыжков. Вода (миски кота, ведро со шваброй, раковина) — мокрый, медленнее.

**Штуки, которые можно использовать [E]:**
| Что | Где | Что делает |
|---|---|---|
| Кран (красный / синий вентиль) | у раковины | горячая или холодная вода, раковина наполняется; в глубине тонешь, струя сбивает с ног |
| Холодильник | дверь снизу | открывается на 15 с; внутри холодно и вкусно (сыр, варенье), сверху морозилка с легендарками — лаз сзади в перегородке. Захлопнется — открывай изнутри |
| Духовка | дверь | откидывается вниз как рампа; внутри печенье на противне, но жарко, а закрытая — печка |
| Ящик | шкаф слева, под столешницей | выдвигается; в первый раз внутри заначка конфет и пушка |
| Выключатель | западная стена, залезть по стене | гасит свет — Человек видит муравьёв только вблизи |
| Тостер | рычаг сбоку | через 2 с ДЗЫНЬ: всех в щелях **катапультирует** под потолок, к верхним шкафам |
| Вентиляция | у кошачьих мисок ↔ над верхними шкафами; у мусорки ↔ над холодильником | мгновенный лаз (с грузом больше 6 не пролезешь) |
| Слив раковины ↔ труба под мойкой | | лаз между раковиной и шкафом под ней |

**Секретки:**
- **Коридор за шкафами** — шкафы не доходят до стены, сзади тёмный проход вдоль всей стены (пыль, потерянный лут).
  Входы: через дыру в задней стенке шкафа под мойкой, щель между столешницей и холодильником, под холодильником.
- **Под холодильником** можно проползти (он на ножках), там монетка и крошки.
- **За холодильником** лужа и **оголённый провод**: раз в несколько секунд искрит, бьёт током рядом и по всей луже.
- За проводом в стене — **мышиная нора**, внутри комната мыши со свечкой и легендарным хабаром.
- **Шкаф под мойкой** — дверца распахнута; внутри труба, моющее средство и **мышеловка** с приманкой.
- **Коробка хлопьев** лежит на боку — внутри тоннель с хлопьями.
- Мелочь на полу и столе (виноград, горошины, крышка, кубики сахара) — **физические**, их можно толкать и сбивать кислотой.

**Жизнь кухни:** время от времени Человек сам открывает холодильник или моет посуду (раковина наполняется).

## Команды для отладки (консоль `;`)

- `Tp X Y Z` — телепорт муравья (например `Tp 3880 4900 60` — к мышиной норе).
- `Peace` — Человек-ИИ перестаёт охотиться (ещё раз — снова охотится).
- `AddBot <команда 0/1> <сколько>` — добавить ботов. `Grab` — как нажать E.
- Запуск с параметрами: `-AntPeace -AntTp=x,y,z[,yaw,pitch] -AntBots=союзники,враги -AntGrabAt=секунды`.

## Мультиплеер

**Проверить в редакторе:** стрелочка у кнопки Play → *Number of Players: 2–4*,
*Net Mode: Play As Listen Server* → Play. Каждое окно — отдельный игрок.

**По сети (LAN или через Radmin VPN / ZeroTier / Hamachi):**
1. Собери игру или запусти *Standalone Game*.
2. Хост открывает консоль (клавиша `~` или `;`) и пишет `HostGame`.
3. Остальные пишут в консоли `JoinGame 192.168.x.x` (IP хоста).
4. Порт — **UDP 7777**. Для игры через интернет без VPN этот порт нужно пробросить на роутере.

## Как устроен код (`Source/AntKitchen`)

| Файл | Что делает |
|---|---|
| `KitchenBuilder` | строит кухню, коридоры и тайники, свет, точки лута; зоны (жар, мёд, вода) 4 раза в секунду |
| `AntMovementComponent` | ползание по любым поверхностям: стены, потолки, переход через углы и края, прилипание после прыжка |
| `AntCharacter` | муравей: процедурные лапы (IK + трипод-походка), температура и статусы, стрельба, лут, груз, смерть |
| `KitchenInteractables` | всё, что можно использовать: двери, кран, свет, лазы, тостер, провод, мышеловка, физические пропы |
| `HumanCharacter` | Человек: тапок, дихлофос, паника, анимация из фигур |
| `HumanAIController` | ИИ Человека: охотится на муравьёв с грузом, топчет, брызгает, обходит препятствия |
| `AcidProjectile` | снаряды муравьёв (сплэш, рикошет, криты, цифры урона) |
| `KitchenLoot` | еда и оружие на полу (реплицируются) |
| `AntTypes` | генерация оружия по редкости и таблицы еды |
| `AntKitchenGameMode` | правила, спавн, раунды, передача Человека игроку и обратно |
| `AntGameState` / `AntPlayerState` | счёт, таймер, лента событий, статистика игроков |
| `AntHUD` | интерфейс: здоровье, груз, карточка оружия, подсказки, маркеры, таблица |
