# 🐜 Ant Kitchen — муравьиный лутер-шутер на кухне

Сетевая игра на Unreal Engine 5 (C++). Вы — муравьи. Лезете на кухню, лутаете ништяки
(крошки, сахар, сыр, торт, мармеладки) и тащите их в муравейник. Мешает **Человек**:
он топчет тапком и брызгает дихлофосом. Человеком управляет ИИ, но любой игрок
может взять его себе (клавиша **H**).

Кухня, муравьи, Человек, лут и интерфейс строятся **кодом прямо при запуске** из
стандартных фигур движка. Поэтому в репозитории нет бинарных ассетов: всё в `Source/`.

## Что нужно установить

1. **Unreal Engine 5.3 или новее** (проект помечен как 5.6; если у тебя другая версия,
   кликни правой кнопкой по `AntKitchen.uproject` → *Switch Unreal Engine version*).
2. **Visual Studio 2022** с компонентами:
   - «Разработка игр на C++» (Game development with C++), там галочка *Unreal Engine installer*;
   - «Разработка классических приложений на C++»;
   - Windows 10/11 SDK и .NET (ставятся вместе с ними).
3. Git, чтобы склонировать репозиторий.

## Как запустить

1. `git clone https://github.com/kisa134/antgame` и переключись на ветку `claude/happy-volta-gwuaqo`.
2. Дважды кликни `AntKitchen.uproject`. На вопрос *«Modules are missing or built with a different
   engine version. Rebuild?»* жми **Yes**: движок сам скомпилирует C++.
   - Если компиляция упала: правый клик по `.uproject` → *Generate Visual Studio project files*,
     открой `AntKitchen.sln`, выбери `Development Editor` и собери (Ctrl+Shift+B).
     Текст ошибки скидывай мне, поправлю.
3. Откроется пустая карта. Жми **Play**: кухня соберётся сама.
   - Если редактор открыл какую-то другую карту: *File → New Level → Empty Level*, сохрани как
     `Kitchen`, жми Play. Игровой режим глобальный, он работает на любой карте.

## Управление

| Муравей | |
|---|---|
| WASD / мышь | бег и прицел |
| ЛКМ | плевок кислотой (зажать — очередь) |
| E | подобрать еду / взять оружие (старое падает на землю) |
| Shift | спринт |
| Пробел | прыжок / оттолкнуться от стены |
| W в стену | **лезть по стене**: так попадаешь на столешницы, стол, холодильник, полку |
| H | стать Человеком |
| Tab | таблица игроков |

| Человек | |
|---|---|
| WASD / мышь | ходить и смотреть |
| ЛКМ | топнуть тапком (под ногой, по полу) |
| ПКМ (держать) | дихлофос (бьёт по муравьям на столах; топливо восстанавливается) |
| H | снова стать муравьём (Человеком опять рулит ИИ) |

## Правила

- Колония побеждает, когда натаскает **1500 сладости**. Если за **10 минут** не успели — побеждает Человек.
- Груз тяжёлый: максимум 10 веса, с грузом ползёшь медленнее. Когда умираешь, груз падает на месте
  («брошенный груз»), и его может подобрать любой муравей.
- **Муравейник** (кучка земли с дыркой у западной стены) — безопасная зона, туда относят еду.
- Если довести Человека до 0 «нервов», он **впадает в панику** на 12 секунд, и колония получает +100.
- Лут по зонам: на полу крошки, на столешницах сахар и сыр, на столе торт и мармелад,
  на холодильнике, верхних шкафах и полке легендарный хабар. Возле помойки много всего.
- Оружие падает с редкостью: Обычное / **Редкое** / **Эпическое** / **Легендарное**
  (цвет луча и свечения). Типы: кислотный плевок, муравьиный дробовик, жвало-пулемёт,
  ядовитая мортира (взрыв), прыгучая капля (рикошет). Есть криты (×2).
- Опасность: одна конфорка на плите **включена** и жарит муравьёв.

## Мультиплеер

**Проверить в редакторе:** стрелочка у кнопки Play → *Number of Players: 2–4*,
*Net Mode: Play As Listen Server* → Play. Каждое окно — отдельный игрок.

**По сети (LAN или через Radmin VPN / ZeroTier / Hamachi):**
1. Собери игру или запусти *Standalone Game*.
2. Хост открывает консоль (клавиша `~` или `;`) и пишет `HostGame`.
3. Остальные пишут в консоли `JoinGame 192.168.x.x` (IP хоста).
4. Порт — **UDP 7777**. Для игры через интернет без VPN этот порт нужно пробросить на роутере.

## Как устроен код (`Source/AntKitchen`)

| Файл | Что делает |
|---|---|
| `KitchenBuilder` | строит кухню, свет и точки лута; жарит муравьёв на конфорке |
| `AntCharacter` | муравей: стрельба, лут, лазание по стенам, переноска груза, смерть |
| `HumanCharacter` | Человек: тапок, дихлофос, паника, анимация из фигур |
| `HumanAIController` | ИИ Человека: охотится на муравьёв с грузом, топчет, брызгает, обходит препятствия |
| `AcidProjectile` | снаряды муравьёв (сплэш, рикошет, криты, цифры урона) |
| `KitchenLoot` | еда и оружие на полу (реплицируются) |
| `AntTypes` | генерация оружия по редкости и таблицы еды |
| `AntKitchenGameMode` | правила, спавн, раунды, передача Человека игроку и обратно |
| `AntGameState` / `AntPlayerState` | счёт, таймер, лента событий, статистика игроков |
| `AntHUD` | интерфейс: здоровье, груз, карточка оружия, подсказки, маркеры, таблица |

## Чего пока нет (следующие шаги)

- **Нормальные модели и анимации.** Сейчас всё собрано из кубов и шаров. Можно взять
  модели муравья и человека с Fab / Sketchfab / Mixamo и подключить вместо фигур.
- **Звук и эффекты** (хлюп кислоты, топот, шипение дихлофоса): нужны звуковые ассеты и Niagara.
- **Главное меню и лобби** (UMG) вместо консольных команд.
- **Поиск игр через Steam** (Online Subsystem Steam), чтобы не возиться с IP и портами.
- Навмеш для ИИ, муравьи-боты, прокачка между раундами, больше комнат.
